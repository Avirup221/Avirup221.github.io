# Avirup Das — Portfolio Website

Personal portfolio website showcasing my work in **AI/ML Engineering**, **Agentic AI**, **RAG Systems**, **Computer Vision**, and **Deep Learning**.

## 🔗 Live: [avirup221.github.io](https://avirup221.github.io)

## ✨ Features

- 🌌 Animated particle canvas background
- 🌙 Dark / Light mode toggle with persistence
- 📱 Fully responsive with mobile hamburger nav
- 🎯 Scroll-reveal animations (IntersectionObserver)
- ✍️ Typewriter hero text effect
- 🃏 Tilt & glow hover effects on project cards
- 📊 Animated stat counters
- 📈 Scroll progress indicator
- ⬆️ Scroll-to-top button

## 🛠️ Tech Stack

- **HTML5** — Semantic markup
- **CSS3** — Custom properties, glassmorphism, responsive design
- **Vanilla JavaScript** — No frameworks, no build tools
- **Google Fonts** (Inter, JetBrains Mono)
- **Font Awesome 6** icons

## 📁 File Structure

```
├── index.html          # Main page
├── style.css           # All styles, design tokens, animations
├── script.js           # Particles, typewriter, nav, reveals, counters
├── My pic.jpg          # Profile photo
├── AvirupResume.pdf    # Resume
└── README.md
```

## 🚀 Deployment

Push this repo to GitHub as `<username>.github.io` and enable GitHub Pages. No build step needed!
